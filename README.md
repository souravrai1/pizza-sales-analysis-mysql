# Pizza Sales Analysis

SQL-based analysis of pizza sales data using MySQL to understand sales performance, customer preferences, and business trends.

## Project Overview

This project analyzes pizza sales data to identify sales patterns, popular pizza types and sizes, category performance, revenue contribution, and ordering trends.

## Business Questions

The analysis focuses on:

- Total number of orders
- Total revenue generated
- Highest-priced pizza
- Most common pizza size
- Top 5 most ordered pizza types
- Total quantity of pizzas sold by category
- Order distribution by hour
- Pizza distribution by category
- Average number of pizzas ordered per day
- Top 3 pizza types by revenue
- Percentage contribution of each pizza type to total revenue
- Cumulative revenue over time
- Top 3 pizza types by revenue within each category
